Categories

Optional. CyberStorm can turn your own category tree into an interactive map, category trails on product and collection pages, and category pages.

1. Create the category tree

In Settings → Custom data → Metaobjects, create one definition per level, for example Department, Category, Subcategory and Product group. Give each a name field and, below the top level, a parent field that references the level above. Then add your entries.

2. Assign products

In Settings → Custom data → Products, add one metafield per level that references the matching metaobject, for example custom.department … custom.product_group. Fill them on each product (bulk editing or a product import is quickest). A product’s trail follows its deepest filled field.

Alternative without product fields: give each category entry a collection field. A product then belongs to the deepest category whose collection contains it.

3. Connect the theme

In Theme settings → Categories, enter each level’s metaobject type handle, the product field keys and the entry field keys (usually name and parent).

4. The category map

Create a page (for example “Categories”) with the categories template, then set it as Category map page. Visitors pan and zoom the map; hovering a node lights its path to the top. A list view shows the same tree as plain links.

5. Category pages (optional)

Add the product category fields as filters in Search & Discovery, then turn on Category pages from filters. Each category then opens All products filtered to it, titled with its name and showing its trail and subcategories.
